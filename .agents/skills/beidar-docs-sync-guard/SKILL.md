# 📚 حارس مزامنة التوثيق (Documentation Sync Guard)

استخدم هذه المهارة في **كل** مهمة. الوثيقة الحاكمة للجرد والمصفوفة هي [`docs/DOCUMENTATION_MAP.md`](../../docs/DOCUMENTATION_MAP.md)، والأداة المنفذة هي [`scripts/docs-gate.mjs`](../../scripts/docs-gate.mjs).

> 🚫 **القاعدة صفر:** يُمنع إغلاق أي مهمة أو تنفيذ `git commit` أو `git push` وبين الكود وتوثيقه انحراف.

## 🚪 البوابة 1 — قبل بدء العمل
1. اقرأ [`docs/DOCUMENTATION_MAP.md`](../../docs/DOCUMENTATION_MAP.md) (الجرد + مصفوفة المزامنة).
2. اقرأ [`docs/features-tracker.md`](../../docs/features-tracker.md) (ما أُنجز · الفجوات · القرارات المحمية).
3. اقرأ مهارة مجالك وقاعدة النطاق في `.agents/`.
4. **أعلن في أول رد** قائمة المستندات التي سيتغيرها العمل.
5. لا رقم ولا مسار من الذاكرة — تحقق بالأمر أو بالبحث.

## 🔁 مصفوفة المزامنة السريعة
| ما تغيّر | المستندات الإلزامية في نفس الجلسة |
|---|---|
| خدمة/خدمات Go أو عقد IPC | `CHANGELOG.md` + `docs/architecture.md` + مزامنة mock الـ E2E |
| قاعدة البيانات أو مهاجرة | `CHANGELOG.md` + `docs/database_and_concurrency.md` |
| الأمان أو التشفير أو الصلاحيات | `CHANGELOG.md` + `docs/security.md` |
| الشبكة المحلية | `CHANGELOG.md` + `docs/lan_network.md` |
| واجهة/ميزة ظاهرة | `CHANGELOG.md` + `docs/features-tracker.md` (+ `README.md` عند تغيير ميزة معروضة) |
| اختبارات أو إعداداتها | `CHANGELOG.md` + `docs/testing.md` + بلوك `docs-metrics` في الخريطة |
| الطباعة | `CHANGELOG.md` + هذا الجرد + مراجعة `.agents/rules/printing-hardware.md` |
| قاعدة حاكمة | `AGENTS.md` + ملف القاعدة/المهارة المعنية + حذف أي تكرار |
| حذف/نقل ملف | `CHANGELOG.md` + الخريطة + كل مرجع للملف (`git grep`) |

## ⛔ البوابة 2 — قبل الكومت
```bash
node scripts/docs-gate.mjs --strict-refs
```
يفشل الكومت إذا:
- انحرفت الأرقام المرجعية عن الواقع (ملفات اختبار Vitest/E2E/Go/مستندات).
- وُجد مستند في `docs/*.md` أو مجلد فرعي غير مسجل في الجرد.
- تغيّر كود بلا أي تحديث توثيق مرافق.
- انحرف دليل كود مُثبَّت في `CODE_ASSERTIONS` (عاد عيب وسم «مُصلح» أو حُذف دليله).
- وُجد مرجع مسار ميت في `AGENTS.md` أو `.agents/` (صارم مع `--strict-refs`).

## 🚀 البوابة 3 — قبل الدفع
```bash
node scripts/docs-gate.mjs --push
```
- يفحص مدى كل الكومتات غير المدفوعة بنفس المعايير.
- **CI خط الدفاع الأخير:** وظيفة `docs-gate` في [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml).
- لا `push` بلا إذن صريح من المالك.

## 📏 ضوابط الأرقام والادعاءات
1. كل رقم في أي مستند يأتي من **أمر مُشغَّل** ويُذكر بجانبه في الخريطة.
2. أرقام الملفات في بلوك ` ```docs-metrics ` — تُتحقق آلياً وتُحدَّث بالأمر.
3. أعداد الحالات (عدد الاختبارات) لا تُكتب إلا بعد تشغيل المجموعة فعلياً مع تاريخ التحقق.
4. أي ادعاء «مكتمل» يُسند إلى `ملف:سطر` أو نتيجة اختبار — لا إلى تقرير قديم.
5. يُوثَّق المنفذ فعلاً؛ غير المنفذ يُكتب في «الفجوات المتبقية» في المتتبع.

## 🕘 التاريخ لا يُعاد كتابته
`CHANGELOG.md` وتقارير المراجعة وسجل الجلسات: **إلحاق وتصحيح مؤرخ فقط**. عند الإصلاح: علّم البند ✅ مع التاريخ + أضف سطراً في `CHANGELOG.md` + حدّث المتتبع.

## 🚑 مفتاح الطوارئ
`BEIDAR_DOCS_GATE=off` — لحالة طارئة مبررة فقط، ويُذكر السبب في رسالة الكومت.
